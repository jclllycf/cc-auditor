# 合成报告示例

全部数据来自公开离线 fixture，synthetic=true；没有读取真实电脑、账号、Profile 或代理。示例故意保留浏览器 DNS 的测量缺口，说明高健康分与仍需补证可以同时存在。数字不构成对任何真实用户的建议。

- brief-zh.pdf：两页简明报告。
- technical-zh.pdf：39 页完整技术报告，保留公式和证据。
- evidence-checklist-zh.pdf：条件式补证清单。
- evidence.synthetic.json：三份报告使用的同一合成证据。

三份均已逐页渲染、检查中文提取和页面边界；这是 PDF 工程验收，不是一次真实用户环境验收。日常程序不会把这些合成样例当成本机检测结果。
