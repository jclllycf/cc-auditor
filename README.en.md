# CC Auditor — Pre-use Windows environment check for Claude

**Recommended: run the local Agent Skill + MCP Toolkit.** A standalone Windows scanner is available as a fallback.

[中文使用说明](README.md) · [Step-by-step Agent guide (Chinese)](AGENT_QUICKSTART_ZH.md) · [Installation](INSTALL_WINDOWS_ZH.md) · [MCP configurations](MCP_CONFIGURATION_ZH.md) · [Privacy](PRIVACY_ZH.md) · [Support](SUPPORT_MATRIX_ZH.md)

CC Auditor examines a Windows computer before first use of Claude. It checks OS, everyday browser profiles, relevant proxy rules and consented neutral network tests, then writes Chinese PDF reports. Claude, Python, an SDK and Claude credentials are not prerequisites.

## Recommended: run it with a local Agent

1. [Download the Windows x64 portable ZIP and SHA256SUMS.txt from the GitHub prerelease](https://github.com/jclllycf/cc-auditor/releases/tag/v3.6.0-beta.1). GitHub's autogenerated Source code archive is **not** the Windows application.
2. Extract the complete archive into a writable directory, e.g. `C:\Tools\CC-Auditor`. Do not separate the EXE and `_internal` folder. See [Windows setup](INSTALL_WINDOWS_ZH.md).
3. Use any Agent that supports authorized access to your Windows machine and a suitable local MCP interface; install the `cc-auditor-preflight` Skill and register the Toolkit as a local tool in the Agent's supported configuration. See the [Agent-agnostic guide](AGENT_QUICKSTART_ZH.md) and [MCP technical notes](MCP_CONFIGURATION_ZH.md). Brand-specific snippets are examples, not requirements.
4. Copy the Agent prompt from the guide. The Agent calls `audit_capabilities`, then `prepare_deep_preflight` and `run_approved_deep_preflight(scan_id)`. **You personally approve the native Windows consent form.**
5. Read the summarized positive environment health scores and local PDF locations. Full evidence is not automatically uploaded to your Agent provider.

**Without an Agent:** extract the ZIP, open the everyday browser profile you want to check, and double-click `CC_Auditor\启动预检.cmd`. The portable Toolkit runs without an Agent.

## Privacy and limitations

- Separate Desktop, Web, CLI and API technical-readiness assessments (100 is healthiest); they are not ban probabilities or eligibility guarantees.
- No new Claude/Anthropic requests by the preflight scanner; consented neutral receivers may observe IP, DNS and TLS information.
- Missing a Claude installation, SDK, historic session or optional physical-location declaration is not a technical fault.
- The Windows ZIP is publicly published as a prerelease, while the full source integration remains in [draft PR #1](https://github.com/jclllycf/cc-auditor/pull/1). End-to-end Agent orchestration and complete proxy compatibility are not yet claimed.
